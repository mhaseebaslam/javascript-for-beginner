# Visual Studio Code keyboard shortcuts

Shortcuts depend on your operating system and custom key bindings. Use the official references for the complete, current list:

- [Windows](https://code.visualstudio.com/shortcuts/keyboard-shortcuts-windows.pdf)
- [macOS](https://code.visualstudio.com/shortcuts/keyboard-shortcuts-macos.pdf)
- [Linux](https://code.visualstudio.com/shortcuts/keyboard-shortcuts-linux.pdf)

## Useful starting points

| Action | Windows / Linux | macOS |
| --- | --- | --- |
| Command Palette | `Ctrl+Shift+P` | `Cmd+Shift+P` |
| Quick Open | `Ctrl+P` | `Cmd+P` |
| Find in file | `Ctrl+F` | `Cmd+F` |
| Save | `Ctrl+S` | `Cmd+S` |
| Toggle terminal | `` Ctrl+` `` | `` Ctrl+` `` |
| Format document | `Shift+Alt+F` | `Shift+Option+F` |

You can search for any action in the Command Palette, or open **File → Preferences → Keyboard Shortcuts** (on macOS, **Code → Settings → Keyboard Shortcuts**) to inspect or customize bindings.
