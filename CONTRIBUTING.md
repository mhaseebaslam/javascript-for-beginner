# Contributing

Improvements that make the lessons more accurate, clear, or approachable are welcome.

## Guidelines

- Keep each example focused on the chapter topic and runnable with Node.js 22 or newer.
- Prefer built-in APIs and avoid adding dependencies for small demonstrations.
- Explain non-obvious concepts in comments or the corresponding lesson text.
- Keep exercise instructions separate from example code.
- Do not include personal data, credentials, or machine-specific paths.

## Before opening a pull request

1. Run `npm test` from the repository root.
2. Check that README links and lesson references point to existing files.
3. Describe what changed and how it helps learners.
