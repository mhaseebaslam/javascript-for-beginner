# Setup checklist

Complete these steps before starting the programming exercises.

## Install and verify

- [ ] Install Node.js 22 or newer from [nodejs.org](https://nodejs.org/).
- [ ] Install a text editor, such as [Visual Studio Code](https://code.visualstudio.com/).
- [ ] (Optional) Install Git if you want to clone or contribute to this repository.
- [ ] Open a terminal and run `node --version` and `npm --version`.
- [ ] From the repository folder, run `npm test`.

## Practice

1. Run `node setting-up/intro_to_programming.js`.
2. Change a message in the file and run it again.
3. Create a file named `hello.js` with a `console.log()` statement and run it with `node hello.js`.

You are ready when Node.js runs your files and you can see their output in the terminal.
